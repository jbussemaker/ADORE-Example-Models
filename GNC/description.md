# Guidance, Navigation and Control

This architecting problem represents a simple assignment problem that could
be found during the design of a Guidance, Navigation & Control (GNC) system:
connect 3 sensors to 3 computers, and select the type (relating to the
reliability and mass of the components) of sensors and computers. The design
space represents a trade-off between system reliability and mass.

For more information, please refer to the original problem description in
section 15.3 of:
Crawley et al., *System architecture: strategy and product development for
complex systems*, Peason Education, 2015.
