# Apollo Mission Architecture

The Apollo mission architecture problem contains choices related to the moon
mission: Earth-orbit-rendezvous, lunar-orbit-rendezvous, crew assignment, fuel
type selection, etc.

This architecture problem serves as a simple demonstration of the capabilities
of ADORE and the Architecture Design Space Graph (ADSG). The design space
contains 108 architectures that can all be evaluated using provided code. The
result is a Pareto front of optimal architectures, where mass-to-orbit (proxy
for cost) is traded-off against the probability of mission success.

For more details, please refer to section V of:
[System Architecture Design Space Exploration: An Approach to Modeling and Optimization](https://arc.aiaa.org/doi/10.2514/6.2020-3172)
