# Jet Engine Architecting (pyCycle)

This model represents a jet engine architecture design space that uses pyCycle
for thermodynamic cycle analysis. The evaluation code has been developed as
part of the MSc thesis of Thibault De Smedt. The ADORE model has been developed
afterwards to demonstrate real optimization capabilities of ADORE.

For more details and results, please refer to:
[System Architecture Optimization: An Open Source Multidisciplinary Aircraft Jet Engine Architecting Problem](https://arc.aiaa.org/doi/10.2514/6.2021-3078) (note that this paper doesn't use the ADORE architecture model!)
